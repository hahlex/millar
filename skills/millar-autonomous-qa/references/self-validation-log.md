### Weaknesses and Gaps Exposed Across Run 1 and Iteration 1 Review/Challenge

1. **`route_scopes` nested bracket parser fragility and `roles` pollution**: `scripts/discover-surface.mjs` and `scripts/runners/api-fuzz-stateful.py` initially matched `route_scopes: [...]` non-greedily (`"all"`/`"any"` leaked into `roles`), then failed on string literals containing `]` (`'weird]scope'`), escaped quotes, `//` or `/* */` comments, and mixed `route_scopes` arrays with bare strings; additionally `scripts/discover-surface.mjs` merged permission scopes (`courses:read`, `payroll:write`) into `coverage.roles` and `scripts/runners/api-fuzz-stateful.py` called `mark_role(tenant_lbl)` adding raw tenant UUIDs to `coverage.roles`.
2. **Suppressed `spec_gap` when static catalog fallback existed**: When `:3200` returned HTTP `404` for `/openapi.json` and `/v1/openapi.json` while `route-catalog.generated.ts` was present, `scripts/discover-surface.mjs` suppressed `QA-DISC-001` (`spec_gap`), leaving `specGaps: 0` in `memory/findings-ledger.json` and `reports/autonomous-qa-validation-report.html`.
3. **False-positive `RESOLVED` regression scripts**:
   - `scripts/run-qa-loop.mjs` (`buildReproScriptSource`) overwrote the origin in `finding.reproCommand` (`http://127.0.0.1:8100`) with `defaultApiOrigin` (`http://localhost:3200`), causing `:8100` `runtime_degraded` reproducers to hit `:3200` (`404`) and falsely exit `0` (`RESOLVED`).
   - `scripts/runners/ui-explorer.mjs` (`buildUiReproScript`) generated unauthenticated contexts for auth-gated routes and `/api/v1/*` `500` findings, falsely exiting `0` (`RESOLVED`) instead of requiring `--token-env` / runtime `QA_TOKEN_*`.
   - `scripts/runners/api-fuzz-stateful.py` (`build_py_repro_script`) omitted `tokenEnv` runtime lookup on IDOR/auth findings, sending `"Bearer [REDACTED]"` and falsely exiting `0` on `401`.
   - `scripts/runners/ai-eval-promptfoo.mjs` emitted `--ai-url undefined` in `reproCommand` when run with `--ai-provider` without `--ai-url`.
4. **Secret redaction gaps in generated artifacts**: `build_py_repro_script` (`scripts/runners/api-fuzz-stateful.py`) and `scripts/report-html.mjs` needed full redaction of JWTs, `X-Api-Key`, `Cookie`, `X-Auth-Token`, sensitive `json_body` keys (`password`, `token`, `secret`), query params (`?api_key=`, `?token=`, `?password=`), Bearer tokens, and Postgres/Redis DSNs before `escapeHtml()` and `write_text_atomic()`.
5. **Cleanup leak on budget exhaustion**: `ItemsCrudStateMachine.teardown` and Phase 3 Schemathesis cleanup in `scripts/runners/api-fuzz-stateful.py` skipped `DELETE` when `requests_used >= max_requests`, leaving orphan items on tight budgets.
6. **UI explorer hydration, k6 auth, Toxiproxy default probe, HTML table parser, CLI `--pg-query`, and durable evidence**:
   - `scripts/runners/ui-explorer.mjs` missed `tokenEnv`, `localStorageEntries`, hydration wait, `/v1/` tracking, and `WorkspaceChooser` fallback, and saved finding screenshots inside ephemeral `test-results/screenshots/` deleted by `scripts/cleanup.mjs` (plus left orphaned unreferenced regression files on deduplication).
   - `scripts/runners/concurrency-k6.mjs` lacked `tokenEnv` auth support; `scripts/runners/resilience-toxiproxy.mjs` probed `/` (`404`) instead of `/healthz`; `scripts/report-html.mjs` (`parseToolSummaryRows`) misparsed an escaped `\|` in `references/tool-selection.md` Section 5 into Section 1; and `scripts/run-qa-loop.mjs` `main()` omitted `--pg-query`.
